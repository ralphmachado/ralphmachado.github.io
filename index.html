HTML CHEAT SHEET

Quick reference guide for HTML elements and attributes

Basic Structure

DOCTYPE

Tells browser this is HTML5

<!DOCTYPE html>

html

Root element that wraps everything

<html lang="en"></html>

head

Contains metadata and page info

<head> <meta charset="UTF-8"> <title>Page Title</title> </head>

body

Contains all visible content

<body> <!-- your content here --> </body>
Text Elements

h1 to h6

Headings from biggest to smallest

<h1>Main Heading</h1> <h2>Subheading</h2>

p

Paragraph for blocks of text

<p>This is a paragraph.</p>

strong and b

Make text bold

<strong>Important</strong> <b>Bold text</b>

em and i

Make text italic

<em>Emphasized</em> <i>Italic text</i>

br

Line break tag

First line<br>Second line
Lists

ul

Unordered list with bullet points

<ul> <li>Item 1</li> <li>Item 2</li> </ul>

ol

Ordered list with numbers

<ol> <li>First</li> <li>Second</li> </ol>

li

List item tag

<li>List item</li>
Links and Images

a

Link to other pages

<a href="https://example.com">Link Text</a> <a href="#section">Internal Link</a>

img

Display images

<img src="image.jpg" alt="Description">
Forms

form

Container for input fields

<form action="/submit" method="post"> </form>

input

Different types of input fields

<input type="text" name="username"> <input type="email" name="email"> <input type="password" name="pass">

button

Clickable button

<button type="submit">Submit</button>

label

Label for inputs

<label for="name">Name:</label> <input id="name" type="text">

textarea

Multi-line text input

<textarea rows="4" cols="50"></textarea>
Semantic Elements

header

Top section of page

<header> <h1>Site Title</h1> </header>

nav

Navigation menu container

<nav> <a href="#">Home</a> </nav>

main

Main content area

<main> </main>

footer

Bottom section of page

<footer> <p>Copyright 2024</p> </footer>

article

Self-contained content

<article> <h2>Article Title</h2> </article>

section

Group related content

<section> <h2>Section Title</h2> </section>
Tables

table

Create a table

<table> <tr> <td>Cell</td> </tr> </table>

tr

Table row

<tr> <td>Data</td> </tr>

th

Table header cell

<th>Header</th>

td

Table data cell

<td>Data</td>
Media Elements

video

Embed video files

<video controls> <source src="video.mp4" type="video/mp4"> </video>

audio

Embed audio files

<audio controls> <source src="audio.mp3" type="audio/mpeg"> </audio>
