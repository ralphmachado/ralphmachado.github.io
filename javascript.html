JAVASCRIPT CHEAT SHEET

Essential JavaScript syntax and programming concepts

Variables

let

Variable that can change

let age = 25; age = 26; // can change

const

Variable that cannot change

const name = 'John'; // name = 'Jane'; // this will error

var

Old way to declare variables

var count = 10;
Data Types

String

Text data

let text = 'Hello'; let name = "World"; let message = `Hi ${name}`;

Number

Numbers and decimals

let age = 25; let price = 19.99;

Boolean

True or false

let isActive = true; let isComplete = false;

Array

List of items

let fruits = ['apple', 'banana']; fruits[0]; // 'apple' fruits.length; // 2

Object

Store related data together

let person = { name: 'John', age: 30 }; person.name; // 'John'
Functions

Function Declaration

Regular function

function greet(name) { return `Hello ${name}`; } greet('John');

Arrow Function

Shorter way to write functions

const add = (a, b) => a + b; const square = x => x * x;

Function Expression

Function in a variable

const multiply = function(a, b) { return a * b; };
DOM Manipulation

querySelector

Select first matching element

const element = document.querySelector('.myClass'); const id = document.querySelector('#myId');

querySelectorAll

Select all matching elements

const elements = document.querySelectorAll('div');

addEventListener

Listen for events

button.addEventListener('click', () => { console.log('Clicked!'); });

innerHTML and textContent

Change element content

element.innerHTML = '

HTML

'; element.textContent = 'Text only';

classList

Add or remove classes

element.classList.add('active'); element.classList.remove('hidden'); element.classList.toggle('show');

createElement

Create new element

const div = document.createElement('div'); div.textContent = 'New element';
Conditionals

if else

Check conditions

if (age >= 18) { console.log('Adult'); } else { console.log('Minor'); }

Ternary Operator

Shorthand for simple if/else

const status = age >= 18 ? 'Adult' : 'Minor';

switch

Check multiple values

switch(day) { case 'Mon': console.log('Start'); break; default: console.log('Other'); }
Loops

for loop

Loop a set number of times

for (let i = 0; i < 5; i++) { console.log(i); }

while loop

Loop while a condition is true

let i = 0; while (i < 5) { console.log(i++); }

for...of

Loop over iterable objects (arrays)

for (const fruit of fruits) { console.log(fruit); }

forEach

Array method for iterating

fruits.forEach(fruit => { console.log(fruit); });
