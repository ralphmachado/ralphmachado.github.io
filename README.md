# 🌐 Ralph Machado's Personal Website

## Project Overview
This repository contains the source code for my personal website/portfolio, hosted using GitHub Pages. The site showcases my skills, projects, and contact information.

It is built with a focus on clean design, performance, and a smooth dark-mode user experience, featuring a custom orange accent color palette.

## Technologies Used
* **HTML5**
* **CSS3** (Custom Night Mode Theme)
* **JavaScript**

## 🚀 Live Site
You can view the live, deployed version of the website here:
[https://ralphmachado.github.io/](https://ralphmachado.github.io/)

## Installation and Setup (For Developers)
If you wish to run or contribute to this code locally:

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/ralphmachado/ralphmachado.github.io.git](https://github.com/ralphmachado/ralphmachado.github.io.git)
    ```
2.  **Navigate to the folder:**
    ```bash
    cd ralphmachado.github.io
    ```
3.  Open the `index.html` file in your preferred web browser to view the site.
