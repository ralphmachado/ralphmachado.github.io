CSS CHEAT SHEET

Comprehensive guide to CSS properties and styling

Selectors

Element Selector

Select all elements of a type

p { color: blue; }

Class Selector

Select by class name

.myClass { font-size: 16px; }

ID Selector

Select by unique ID

#myId { background: red; }

Universal Selector

Select everything

* { margin: 0; padding: 0; }

Descendant Selector

Select nested elements

div p { color: green; }
Box Model

margin

Space outside the element

margin: 10px; margin: 10px 20px; margin-top: 5px;

padding

Space inside the element

padding: 15px; padding: 10px 20px;

border

Border around element

border: 2px solid black; border-radius: 5px;

width and height

Size of the element

width: 300px; height: 200px; max-width: 100%;

box-sizing

How size is calculated

box-sizing: border-box;
Typography

font-family

Set the font type

font-family: Arial, sans-serif;

font-size

Size of text

font-size: 16px; font-size: 1.2rem;

font-weight

How thick the text is

font-weight: bold; font-weight: 600;

text-align

Align text horizontally

text-align: center; text-align: justify;

line-height

Space between lines

line-height: 1.6;

text-decoration

Underline, strikethrough, etc

text-decoration: underline; text-decoration: none;
Colors and Backgrounds

color

Text color

color: #333; color: rgb(255, 0, 0); color: rgba(0, 0, 0, 0.5);

background-color

Background color

background-color: #f0f0f0; background-color: transparent;

background-image

Set background image

background-image: url('image.jpg'); background-size: cover; background-position: center;

opacity

Make element transparent

opacity: 0.5;
Flexbox

display flex

Turn on flexbox

display: flex;

justify-content

Align items horizontally

justify-content: center; justify-content: space-between; justify-content: flex-start;

align-items

Align items vertically

align-items: center; align-items: flex-start;

flex-direction

Direction of flex items

flex-direction: row; flex-direction: column;

flex-wrap

Allow items to wrap

flex-wrap: wrap; flex-wrap: nowrap;
CSS Grid

display grid

Turn on grid layout

display: grid;

grid-template-columns

Set up columns

grid-template-columns: 1fr 1fr 1fr; grid-template-columns: repeat(3, 1fr);

gap

Space between grid items

gap: 20px; column-gap: 10px; row-gap: 15px;
Positioning

position

Position type of element

position: relative; position: absolute; position: fixed; position: sticky;

top right bottom left

Position offset

top: 10px; left: 20px;

z-index

Stacking order

z-index: 100;
Transitions and Animations

transition

Smooth property changes

transition: all 0.3s ease; transition: background-color 0.5s;

transform

Move, rotate, scale elements

transform: scale(1.1); transform: rotate(45deg); transform: translateY(-5px);

hover

Style when hovering

button:hover { background-color: blue; }
Responsive Design

Media Queries

Different styles for screen sizes

@media (max-width: 768px) { .container { width: 100%; } }

Viewport Units

Size relative to screen

width: 100vw; height: 100vh;
